# Desktop workbench

Mode: Operate.

Scope: Full visual redesign of Projects, Sessions, session transcript, Accounts, and Settings. Preserve all product facts, navigation, controls, workflow, and accessibility behavior.

Audience and task: Developers use the Electron app to delegate work in local project folders through an existing signed-in web provider account. They start tasks, follow sessions, inspect tool activity, approve sensitive actions, manage accounts, and check local setup.

## Direction contract

THESIS: A local coding workbench framed like a battered arcade machine: graphite chassis, hazard-yellow instrumentation, manga-print grit, and vermilion reserved for urgency. The HUD frames real work; it never invents game telemetry.

OWN-WORLD: Graphite owns the shell and page canvas; paper-white keeps forms, cards, transcript, and code readable. Hazard yellow marks selection, industrial trim, and decorative module IDs. Vermilion marks primary actions, recovery, errors, and permission requests. Heavy panel rules, hazard-stripe edges, calibration ticks, halftone fields, condensed display lettering, and legible workhorse body type define the components. No visual noise enters text-entry, code, or transcript reading surfaces. HUD labels are decoration, never fabricated state.

STORY: Developers can locate a project or saved session immediately, see which account and local workspace are active, then start or continue work. Recovery, errors, and permission requests remain explicit and actionable.

FIRST VIEWPORT: Keep familiar desktop navigation, with a graphite rail and hazard-yellow selected route. Projects leads with the task heading, recent projects and sessions, then a clearly dominant new-conversation form. A machine fascia, calibration ticks, and restrained hazard/screentone trim frame the work; utility and reading regions stay clean, square, and easy to scan. Narrow screens move navigation above content and stack work areas without horizontal scrolling.

FORM: User-selected grunge-industrial arcade HUD layered onto the manga-line brutalist direction. Graphite chassis, white work surfaces, hazard-yellow instrumentation, and vermilion for urgency. Decorative module IDs and tick marks only; actual status comes from application data. Existing product workflows remain unchanged.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
